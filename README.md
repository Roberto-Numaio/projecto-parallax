# 🌄 Parallax Website

A website built with **HTML5 and CSS3**, created to practice building pages with a **Parallax effect**, exploring positioning, background images, sections, and visual effects using only CSS.

## 📌 About the Project

This project was developed as part of my web development studies, focusing on practicing modern page layouts and visual effects using native HTML and CSS features.

The main highlight of the project is the **Parallax effect**, which creates a sense of depth while navigating through the page.

## 🛠️ Technologies Used

* **HTML5** — Page structure and content
* **CSS3** — Styling, layout, and Parallax effect

## ✨ Features

* Responsive layout
* Parallax effect
* Background images
* Multiple content sections
* Navigation between different sections
* CSS-based visual effects

## 🎯 Project Goals

The main goal of this project is to practice:

* Structuring web pages with HTML5
* Organizing layouts using CSS
* Working with background images
* Using `background-attachment`
* Positioning and spacing
* Creating visual effects
* Building responsive layouts

## 📚 What I Learned

While developing this project, I mainly practiced using CSS to create a more dynamic and visually engaging experience without relying on JavaScript or external libraries.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No dependencies or installation are required.
